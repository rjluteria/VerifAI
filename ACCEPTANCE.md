# Acceptance status

This is a private development candidate. Release acceptance is incomplete. Scores describe bounded evaluation cohorts and do not establish universal factual correctness. Expected inputs and labels are frozen before each run; original failures are preserved. Earlier gold adjudication is documented in [the corpus notes](evaluations/GOLD_ADJUDICATION.md).

Origin validation is defense in depth, not client authentication: a non-browser caller knowing an allowed origin can send that header. Sessions, capacity and rate limits are process-local. Backend restarts discard jobs. Already running external calls can finish after a job's soft time budget. Provider agreement and exact quotes do not prove factual truth; unavailable, ambiguous or conflicting evidence must remain Unverified.

Public publication requires user review after final acceptance evidence. Native Windows acceptance and production authentication/operations are not implied by these checks.
