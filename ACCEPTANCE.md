Origin headers are defense in depth and can be forged by non-browser clients. Signed anonymous sessions establish result ownership, not account identity. Capacity, rate limits and job storage are process-local. Backend restarts discard jobs. Turning the extension Off prevents new extension submissions; external requests already accepted by the backend can finish.

Source access is checked from the service at retrieval time and separately observed in the test browser. A user's region, login, network and future page changes may differ. Unavailable or uncertain evidence must remain Unverified. Provider agreement and exact quotation provenance do not establish universal factual truth.

The final acceptance report and every-requirement matrix require user review before repository publication, Chrome Web Store submission, announcement or other public-release actions. The native Windows gate is described in [WINDOWS_ACCEPTANCE.md](WINDOWS_ACCEPTANCE.md).
